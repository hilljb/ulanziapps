# Ulanzi TC002 Apps

Displaying GCP Firestore data on a TC002. Maybe I'll do more later, but see the `firestore_nightscout/` directory for displaying [Nightscout](https://nightscout.github.io/) data I collect from [xDrip](https://navid200.github.io/xDrip/) and place into GCP via my own [xDrip2GCP](https://github.com/hilljb/xdrip2gcp). This is a hack in progress.
